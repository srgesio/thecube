Spec 5 — Visualização 2D do Cubo
Componente que renderiza o cubo "desdobrado" (net/cross layout)
Requisitos:
- Componente CubeVisualizer que recebe cubeState e renderiza o "desdobramento" clássico do cubo:
      [U]
  [L] [F] [R] [B]
      [D]
- Cada célula é um quadrado colorido
- Layout responsivo
- Usar Tailwind para estilização
Critério de aceite: Componente renderiza corretamente o cubo resolvido e após movimentos.
