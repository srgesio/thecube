Spec 6 — Interface do Usuário (Input + Integração)
Interface completa para interação com o cubo
Requisitos:
- Input de texto para digitar notação (ex: R U R' U')
- Botão "Aplicar" para executar a notação
- Botões clicáveis para cada movimento individual (R, L, U, D, F, B e suas variantes)
- Botão "Reset" para voltar ao cubo resolvido
- Botão "Undo" para desfazer último movimento
- Indicador de sequência aplicada (histórico)
- Layout: visualização do cubo à esquerda/cima, controles à direita/baixo
- Responsivo (mobile-friendly)
Critério de aceite: Interface funcional, todos os botões funcionam, notação é aplicada corretamente, cubo atualiza em tempo real.
